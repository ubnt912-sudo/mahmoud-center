# محمود سنتر — النظام المتكامل

نظام Full-Stack لإدارة محل موبايلات: صيانة، نقطة بيع، فواتير، مخزون، اشتراكات إنترنت، رسائل وتقييمات، مع بوابة خاصة لكل زبون.

**التقنيات:** Next.js 15 (App Router) · React 19 · Prisma 6 · PostgreSQL · Tailwind CSS 4 · JWT (jose) · bcrypt · zod · PWA

---

## النشر السريع (الطريقة الموصى بها: Vercel + Neon — مجاني)

### 1) قاعدة البيانات
1. أنشئ حساباً على **neon.tech** ثم مشروعاً جديداً.
2. انسخ رابط الاتصال (Connection string) — يبدأ بـ `postgresql://...`.

### 2) رفع المشروع
1. ارفع هذا المجلد إلى مستودع GitHub جديد.
2. على **vercel.com** اختر *Add New → Project* واختر المستودع.
3. أضف متغيرات البيئة (Environment Variables):

| المتغير | القيمة |
|---|---|
| `DATABASE_URL` | رابط Neon |
| `JWT_SECRET` | نص عشوائي طويل (32 حرفاً أو أكثر) |
| `NEXT_PUBLIC_BASE_URL` | رابط موقعك بعد النشر، مثل `https://mahmoud-center.vercel.app` |

4. اضغط **Deploy**.

### 3) إنشاء الجداول والمدير (مرة واحدة)
من جهازك داخل مجلد المشروع (بعد وضع `DATABASE_URL` نفسه في ملف `.env`):
```bash
npm install
npm run db:setup
```
هذا ينشئ الجداول ويضيف حساب المدير.

> بديل بدون جهاز: في Vercel غيّر *Build Command* مرة واحدة إلى
> `prisma generate && prisma migrate deploy && node prisma/seed.js && next build`
> ثم أعد النشر.

### الدخول الأولي
- البريد: `admin@mahmoudcenter.com`
- كلمة المرور: `Admin@2026`

**غيّر كلمة المرور فوراً** من صفحة المستخدمين.

## النشر عبر Bolt
1. افتح bolt.new واستورد المشروع (ارفع الملفات أو اربط مستودع GitHub).
2. اربط قاعدة PostgreSQL (Supabase من داخل Bolt أو Neon) وضع الرابط في `DATABASE_URL`، وأضف `JWT_SECRET` و `NEXT_PUBLIC_BASE_URL`.
3. شغّل في الطرفية: `npm install && npm run db:setup`
4. استخدم **Deploy** في Bolt.

> ملاحظة: إذا تعذّر تشغيل Prisma داخل بيئة Bolt المعاينة، فالنشر على Vercel + Neon بالخطوات أعلاه يعمل بدون أي تعديل.

## التشغيل محلياً
```bash
npm install
cp .env.example .env        # ضع DATABASE_URL و JWT_SECRET
npm run db:setup            # الجداول + المدير
npm run dev                 # http://localhost:3000
```
بيانات تجريبية للتجربة فقط: `SEED_DEMO=true npm run db:seed`

## ملاحظات تقنية
- كلمات المرور مشفّرة bcrypt (12 جولة)، والجلسة JWT في كوكي `httpOnly` لمدة 7 أيام، مع حد لمحاولات الدخول.
- البيع ونقص المخزون يتمان في معاملة واحدة مع تحقق ذري من الكمية (لا يمكن البيع بأكثر من المتوفر). إلغاء الطلب يعيد الكميات ويلغي الفاتورة.
- حالات الاشتراك تتحدث تلقائياً: ينتهي قريباً قبل 5 أيام، منتهي بعد التاريخ، والموقوف يبقى موقوفاً.
- بوابة الزبون لا تعرض أي بيانات داخلية (سعر الشراء، ملاحظات الفني، أسماء الموظفين)، والرمز UUID غير قابل للتخمين ويمكن إعادة توليده.
- روابط واتساب Click-to-Chat برسائل جاهزة. الإرسال الآلي يحتاج WhatsApp Business API.
- PWA: قابل للتثبيت على الهاتف، مع صفحة "غير متصل". بيانات الـAPI لا تُخزَّن مؤقتاً أبداً.
- فحص الحالة: `/api/health`
